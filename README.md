## FAQ

### What exactly is XCutors?

XCutors is a Windows desktop collection that packages several popular Roblox script executors — Volt, Synapse Z, Potassium, and Wave — together with a universal loader called xcutorsLoader, giving users a single download and unified interface for multiple tools.

### Is XCutors free to use?

Yes, XCutors itself is free to download and distribute. However, some of the individual executors bundled within the package may have their own separate licensing, donation, or access requirements set by their original developers.

### Which executors are included in the package?

The current release includes four executors: Volt, Synapse Z, Potassium, and Wave. The universal xcutorsLoader acts as a hub to initialize, manage, and switch between them without installing each one separately.

### What are the minimum system requirements?

You need a 64-bit Windows 10 or Windows 11 installation, at least 4 GB of RAM, .NET Framework 4.8 or later, and a stable internet connection for first-time setup and auto-updates.

### Why does my anticomponent flag or quarantine the files?

Script executors typically interact with external processes at runtime, which heuristic anticomponent engines may classify as suspicious behavior. These detections are generally false positives. You can add the XCutors installation folder to your anticomponent exclusion list to resolve the issue.

### How do I keep the bundled executors up to date?

xcortorsLoader includes a built-in update checker. When you launch the loader, it automatically compares your local versions against the latest releases and prompts you to update any outdated executor with a single click.

### Can I add my own Lua scripts to the script hub?

Absolutely. Navigate to the scripts directory inside the XCutors folder and place your .lua or .txt files there. They will appear in the script hub's file browser the next time you refresh or restart the executor.

### Which executor should I choose if I'm a beginner?

We recommend starting with Volt or Wave, as both offer straightforward interfaces and broad script compatibility. xcutorsLoader includes a brief comparison panel that highlights the strengths of each executor to help you decide.

### Does XCutors support macOS or Linux?

No. XCutors and all bundled executors are designed exclusively for the Windows platform. There are currently no plans to support macOS or Linux.

### Where can I report bugs or request new features?

Please open an issue on the Issues tab of this GitHub repository. Provide a clear description of the problem or suggestion, your operating system version, and the executor you were using so the maintainers can assist you efficiently.
